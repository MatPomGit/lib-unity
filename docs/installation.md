# Instalacja

Oficjalne Unity CLI i Python 3.11+. `python -m pip install -e .`, następnie `python -m lib_unity status` lub `python -m lib_unity list`. Aby połączyć się z edytorem, najpierw skonfiguruj Unity Pipeline przy użyciu oficjalnego instalatora. Brak potwierdzonej instalacji na Andromedzie i brak wydania do registry.
